# Image Assets

Place the following files here to replace the placeholder/Pexels images:

- `logo.png` — Your business logo (used in navbar, footer, favicon)

All other images (hero, gallery, instructors, services) currently load from Pexels
stock photos via URLs in `src/data/images.ts`. To use your own images instead,
drop the files in this folder and update the paths in `src/data/images.ts`.
